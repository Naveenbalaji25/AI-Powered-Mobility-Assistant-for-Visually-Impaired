# AI Powered Mobility Assistant for Visually Impaired

## Overview

This project is a low-cost AI-powered wearable assistant designed to help visually impaired individuals using real-time object detection, OCR text recognition, GPS assistance, and Raspberry Pi.

---

# Features

- Real-time Object Detection using YOLOv8
- OCR Text Reading
- Voice Assistance
- GPS Location Support
- Raspberry Pi Integration
- Wearable AI Prototype
- Real-Time Camera Processing

---
